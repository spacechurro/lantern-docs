# Lantern docs

Guides for [lantern](https://github.com/spacechurro/lantern), a command that checks whether a URL is up. It supports `check` once or `watch` until interrupted.

- [Getting started](getting-started.md)
- [Commands](cli.md)
- [Configuration](configuration.md)

When a pull request merges in the lantern repo, Grok Build reads that diff next to these pages and opens a pull request here if a user would notice the change. The prompt is [`sync-docs.md`](https://github.com/spacechurro/lantern/blob/main/.github/prompts/sync-docs.md).
